# QA 체크리스트: 배포 알림 (이슈 #2 · #10)

테스트 빌드: preview APK. 결과 칸에 ✅ / ❌ / ⏭(미실시)와 메모를 적는다.
**기대 동작**: 알림 제목은 상태(🚀 시작 · ✅ 완료 · ❌ 실패), 본문은 프로젝트 이름. 탭하면 상태와 관계없이 해당 프로젝트 WebView가 열린다.

## 5. 예외·경계
| # | 항목 | 기대 | 결과 |
|---|---|---|---|
| 5-1 | 알림 권한 거부 | 앱 정상 동작, 🔔 화면에 안내 | |
| 5-2 | 카탈로그에 없는 `projectId` 알림 | 알림은 오고 탭해도 이동하지 않음 | |
| 5-3 | 앱 재설치 후 | 토큰이 바뀌면 시크릿 갱신 전까지 알림이 오지 않음(`DeviceNotRegistered`) | |
| 5-4 | 같은 배포 재실행(re-run) | 알림이 다시 온다(eventId 별도) | |
